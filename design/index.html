Four directions for the portfolio, and the dashboard that goes with each.

Static HTML and CSS, no framework, so the look can be judged before any of it is ported to React. All eight pages use the real content from src/Utils/data.js: the same fourteen builds, the same measured numbers, the same three named references.

The four are not four skins on one layout. They differ in typeface, in grid, and in how structure is expressed: rules, alignment, hairlines, or outlines. Pick one, or say which parts of which.

Reference points: seyidev.com for the tactile editorial energy, impeccable.style for the refine and simplify passes. Avoided throughout: glow and blur, purple-to-blue gradients, glassmorphism, Inter, uppercase eyebrow labels stacked above oversized titles, em dashes in copy, and grids of identical cards.
01 / Instrument Serif + Newsreader + JetBrains Mono

Broadsheet

Editorial print · paper stock · oxide red · hairline rules

Structure comes from a margin column and horizontal rules rather than boxes. Section numbers sit beside the heading on the same baseline, the way a print sidenote does, so nothing reads as a centred label above a giant title.

  • Work set as ruled entries with the measured result in a right rail
  • Method written as two-column prose with a column rule, not six cards
  • Dashboard is a ledger: dense ruled rows, bars drawn as measures

02 / JetBrains Mono throughout

Ledger

Warm near-black · one typeface · flat amber · no glow anywhere

The dark one, deliberately matte. Warm olive-black instead of blue-black, a single flat amber, and not one gradient, blur or glow in the stylesheet. Monospaced end to end, so alignment does the work borders usually do.

  • Work reads as a timestamped log with aligned key/value outcomes
  • Section dividers are rules that carry their own label
  • Dashboard is a three-column operations console with an activity stream

03 / Archivo + IBM Plex Mono

Datasheet

Swiss industrial · visible 12-column grid · safety orange · small tight type

Technical documentation rather than a brochure. The column rules stay visible, every section and figure is numbered, and results sit in a fixed results column beside each item. The densest of the four, and the most obviously engineer-made.

  • Work presented as numbered items with Fig. captions and a results table
  • Copy is short, declarative, and carries its own reference numbers
  • Dashboard is an instrument panel: gauges with tick scales, register table

04 / Bricolage Grotesque + Fraunces + JetBrains Mono

Workshop

Tactile · 2px outlines · flat offset shadows · terracotta, butter, olive

Closest in energy to the seyidev reference, with its own palette and typeface. Hard outlines and flat drop shadows, no blur and no radius. Block sizes and colours vary down the page so it has rhythm instead of a uniform grid.

  • Work blocks alternate between full, half and third width
  • Full-bleed colour bands separate sections instead of more cards
  • Dashboard is a shop-floor board with an uneven coloured scoreboard
