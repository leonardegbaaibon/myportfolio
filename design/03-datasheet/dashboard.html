Swiift, everyday crypto wallet

Swiift

Lead Mobile Developer / Jun 2025 → Jan 2026 / live on both stores / source under NDA

Buy, spend, save, send, pay bills, issue a virtual debit card. The brief was to hide the blockchain entirely, which is mostly a state-consistency problem rather than a crypto one.

Every write is idempotent and the wallet reconciles on resume, because on Lagos mobile data a request can hang for nine seconds and then succeed. The naive version double-spends.
